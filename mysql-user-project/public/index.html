How Verification Flow Works:

1. Registration

Password hashed with bcrypt. 6-digit OTP generated (valid 10 mins) and sent via Nodemailer.

2. OTP Verification

Submits OTP code with expiry check. Unverified users can resend OTP after 60s cooldown.

3. JWT Login

Only verified users can log in. Returns signed JWT token used for product CRUD actions.

🗄️ MySQL Database Schema

schema.sql

1. `users` Table

CREATE TABLE users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(150) NOT NULL UNIQUE,
  password VARCHAR(255) NOT NULL,
  is_verified BOOLEAN DEFAULT FALSE,
  otp VARCHAR(10) DEFAULT NULL,
  otp_expires_at DATETIME DEFAULT NULL,
  otp_last_sent_at DATETIME DEFAULT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_users_email (email),
  INDEX idx_users_is_verified (is_verified)
);

2. `products` Table

CREATE TABLE products (
  id INT AUTO_INCREMENT PRIMARY KEY,
  title VARCHAR(200) NOT NULL,
  description TEXT DEFAULT NULL,
  price DECIMAL(10, 2) NOT NULL DEFAULT 0.00,
  category VARCHAR(100) DEFAULT 'General',
  stock INT NOT NULL DEFAULT 0,
  image_url VARCHAR(500) NOT NULL,
  image_filename VARCHAR(255) DEFAULT NULL,
  image_size INT DEFAULT 0,
  created_by INT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  CONSTRAINT fk_products_user FOREIGN KEY (created_by)
    REFERENCES users(id) ON DELETE CASCADE
);

📡 REST API Endpoints

10 Endpoints
POST /api/auth/register

Registers user, validates inputs, hashes password, generates 6-digit OTP, sends Nodemailer email.

POST /api/auth/verify-otp

Validates OTP code, checks 10-minute expiry, marks user verified in MySQL.

POST /api/auth/resend-otp

Resends OTP with 60-second cooldown protection for unverified users.

POST /api/auth/login

Authenticates password, ensures is_verified = TRUE, issues signed JWT token.

POST /api/products Protected

Multer validates the image (JPG, PNG, WEBP, 5MB limit) and uploads it to Cloudinary. The image URL and product details are saved in MySQL.

PUT /api/products/:id Protected

Updates product. A new image replaces the old Cloudinary image automatically.

DELETE /api/products/:id Protected

Deletes product from MySQL and attempts to remove its Cloudinary image.
